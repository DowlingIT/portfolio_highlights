
# Summary
Built a new module for the LabLynx LIMS (Laboratory Information Management System) to handle information management for the second largest Medical Examiner in the US, which remains in use to this day. Other state and county organization have since adopted this software. All departments in the Medical Examiner office utilize the software - intake, investigations, medical records, X-Ray techs, pathology, tox lab, photography, etc. It includes full auditing and electronic signatures, and is routinely used in court. I handled all aspects of the project, including implementation, project management, design, requirements gathering, as well as most development work. An independent web portal allows the public to make information requests. Automated features were implemented to support sub-contracted testing, which include HL7 data exchange.

The go-live process included on-site training and manuals to tailored to the Medical Examiner's processes.

# Accomplishments
- Replaced a paper-based system, where some data was transcribed to a mainframe, to fully electronic.
- Replaced a mainframe system. A limited sub-set of case information was being transcribed into a mainframe database. This data, going back to 1980, was migrated into the new software.
- The Medical Examiner successfully demonstrated NAMEC and ISO compliance.
- Automated HL7-based data and report exchange for sub-contracted testing.
- A variety of worklists facilitate status and prioritization tracking for work across all departments.
